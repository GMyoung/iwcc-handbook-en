# Illinois Work Comp Handbook · English Reading Edition

Built around the IWCC [2024 revised handbook](https://iwcc.illinois.gov/content/dam/soi/en/web/iwcc/documents/handbook/IWCC%20handbook%2006.06.24.pdf), with the supplied 2013 handbook’s outline retained for 11 chapters and 94 lessons. Each chapter is one continuous reading page. Two filing questions unique to the 2013 outline have been updated for electronic filing.

Each lesson places the handbook’s corresponding answer directly in the reading flow, followed by a specific teaching scenario, its own diagram, and a compact source line. The 94 diagrams use flows, timelines, comparisons, decision paths, and formulas; hovering highlights their steps in sequence. Chapter 9 includes the full statutory body-part schedule. Real court cases identify the worker, dispute, and outcome and link to the Illinois court opinion. Fictional teaching scenarios are labeled.

The left navigation contains only chapters. Search jumps to a specific place within a chapter, and old `#/lesson/<number>` links still reach that place. Readers can mark each lesson learned without answering a question. Two optional multiple-choice questions at the end of each chapter give feedback and links back to the relevant lesson. Text-size control, saved progress, a mobile chapter drawer, and reduced-motion support are included.

## Run locally

```bash
npm ci
npm run dev
npm run build
```

Push `main` to publish through GitHub Actions and GitHub Pages. No API key, backend, or paid image service is required; GPT API spend is $0. The Chinese edition lives in a [separate repository](https://github.com/GMyoung/iwcc-handbook-zh).

This is educational material. Individual outcomes depend on facts and current law. Calculator illustrations omit statutory minimums and maximums. The [IWCC handbook page](https://iwcc.illinois.gov/about/handbook.html) was checked on September 28, 2026.
